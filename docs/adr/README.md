# Architecture decision records

Each ADR lives in `docs/adr/NNNN-<topic>.md` (four-digit number, next free one). Decision numbers in the specs (`docs/spec-*.md`) are separate and must not clash across specs and open PRs.

## Status

- **Proposed:** draft under review; not binding.
- **Accepted:** approved; binding.
- **Superseded:** replaced by a later ADR (link it).
- **Deprecated:** no longer applies, with no replacement.

## Template

```markdown
# ADR NNNN: Title

- **Status:** Proposed | Accepted | Superseded by ADR NNNN | Deprecated
- **Date:** YYYY-MM-DD
- **Spec:** link and decision numbers

## Context
## Decision
## Consequences
## Alternatives considered
```
