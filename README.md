# vibe-backend SDK

Rust-core SDK for vibe-backend. Write API, model and method definitions in natural-language markdown; they are compiled into reviewed lock files and a signed manifest, then run serverless with cold start.

See [docs/spec-v1.5.md](docs/spec-v1.5.md) for the full specification.
