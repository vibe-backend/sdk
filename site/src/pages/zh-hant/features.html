功能

規格保證的一切。

以下每項功能都直接來自 規格 v1.5。

Markdown 就是原始碼

model、method、API、pipeline 與 provider 全部以自然語言 Markdown 撰寫。可以加上 method: POST 之類的 frontmatter，但並非必要。

以資料夾決定路由

入口檔放在 api/{definition}/{version}/{feature}/{feature}.md，對應路由 /{definition}/{version}/{feature}。版本只由路徑決定（v1、v2…），v1 支援 HTTP GET、POST、PUT、DELETE。

經審核的 lock 檔

每個 source 都會編譯成結構化的 .lock.md。涉及安全項目的 lock 一律需要人工確認，並綁定 commit hash；高風險變更須由兩位非作者確認。

簽名 manifest 與 serverless 執行

已確認的 lock 會合併成一份簽名 manifest。請求以冷啟動方式執行（p95 目標低於 1 秒），執行階段永遠不會讀取 source Markdown。

確定性驗證

獨立驗證器會檢查 lock 完整性、路由、pipeline 與認證、provider、RLS 及公開存取。編譯器沒有網絡與任何工具權限，所用的模型 snapshot 則透過 compiler hash 固定下來。

內建帳戶安全

refresh token 每次使用都會輪換，重用舊 token 會撤銷整個 token 家族；access token 最長 1 小時；密碼至少 12 個字元並檢查是否外洩；15 分鐘內失敗 5 次即鎖定帳戶。

租戶隔離

預設使用 PostgreSQL provider 並啟用 row-level security。lock 禁止 DDL 與 TRUNCATE，公開寫入則受配額、欄位白名單與審計紀錄限制。

營運

狀態碼遵循 RFC 9110，錯誤回應格式統一，附結構化日誌；緊急 kill switch 可在 30 秒內（p99）停用個別端點，無須重新部署。
