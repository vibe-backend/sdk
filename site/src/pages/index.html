Write your backend in Markdown.

vibe-backend is a Markdown-driven serverless backend. You describe API entry points, models and methods in plain natural-language .md files. The Rust-core SDK compiles them into reviewed lock files and a signed manifest, then runs every request with a Lambda-style cold start.

Quick start Read the spec

How it works

  1. Source — write api/{definition}/{version}/{feature}/{feature}.md in natural language: what the endpoint does, its input, output, errors and permissions.
  2. Lock — the compiler turns each source into a structured {feature}.lock.md, checked by an independent deterministic validator and confirmed by a human reviewer in the PR.
  3. Manifest — on deploy, all confirmed locks are merged into one signed manifest. The runtime loads only the manifest and never interprets natural language.

Best practices built in

The SDK picks up the logic described in your Markdown and pairs it with built-in, platform-enforced implementations: refresh-token rotation, password policy, account lockout and rate limiting, tenant isolation with RLS, audit logging, an emergency kill switch and more — so each feature file only has to describe your business intent.
